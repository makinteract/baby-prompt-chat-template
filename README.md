# Baby-Prompts Chat Template

![demo](https://cdn-images-1.medium.com/max/2000/1*SP9ZESl6HE6gQXK4xyCEmg.gif)

This example shows how to use the library baby-prompts to create a ChatGPT-like chat in the CLI using the [baby-prompts](https://www.npmjs.com/package/baby-prompts) NodeJS library.

For a full explanation of how to use this code and its parts, please refer to [this article](https://medium.com/@andrea_36977/fb8ad332cf71).

## How to run the code

```sh
git clone https://github.com/makinteract/baby-prompt-chat-template
cd baby-prompt-chat-template
npm install
npm run start
```

Before running your code, ensure you have a `.env` file in the root folder of the project containing your API key as follows:

```sh
OPENAI_API_KEY=<your api key>
```

You may find your API key [at this link](https://platform.openai.com/api-keys).
